Color-code syndromes at distance 3

Seven data qubits and three tiles; each tile carries a Z-check (detects bit flips) and an X-check (detects phase flips). Select a qubit to cycle its error through none, X, Z and Y. The decoder applies the minimum-weight correction implied by the syndrome.

Outer ring: orange = bit flip; indigo = phase flip; both = Y

Every single error has a unique syndrome, so any one error is corrected. Some pairs of errors share a syndrome with a single error, and the correction then completes a logical error: the code has distance 3.

Detection events in space and time

A five-qubit repetition code with four Z-checks between neighboring qubits, measured for ten rounds. Insert data-qubit errors (persistent) and measurement errors (single round) and observe the resulting detection events.

A detection event D marks a change in the outcome O of check c between rounds r − 1 and r.

A data-qubit error in the interior produces two detection events in the same round on adjacent checks; a measurement error produces two in consecutive rounds on the same check; an error on a boundary qubit produces one. The decoder pairs events into the most probable explanation.

Clifford gates and the magic state

Real qubit states lie on a circle at angle θ. The gates X, Z and H act as reflections, so states at multiples of 45° (stabilizer states) are only ever permuted among themselves, and the magic state at 22.5° can never be produced from them.

Teleportation by a joint-parity measurement

Qubit 1 holds the state at angle θ and qubit 2 starts in |0⟩. Measuring the joint X-parity and then qubit 1 selects one of four branches with equal probability; the recorded Pauli correction restores the state on qubit 2. A misread parity selects the wrong correction.
